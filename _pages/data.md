##### Simple Stellar Populations

<hr style="height:1px; background-color:#808080;">

Simple Stellar Population (SSP) template files for use with the <a href="https://dsps.readthedocs.io/en/latest/index.html">Differentiable Stellar Population Synthesis (DSPS)</a> and <a href="https://tengri-project.org">Tengri</a>, from FSPS, ProGeny, BPASS, BC03, E-MILES, MILES, sMILES, Maraston (2005), and MaStar, including alpha-enhanced models. All of these templates are uniformly formatted in an easy-to-understand HDF5 format for ease of use. I formatted the files. Credit for the models goes to the original developers.

<strong>For more information and data access, click <a href="https://halos.as.arizona.edu/suchethacooray/ssp-spectra/">here</a>. </strong>

A second set is for use with DSPS and Tengri as well. This set is the <a href="https://github.com/cconroy20/fsps">Flexible Stellar Population Synthesis (FSPS)</a> templates with nebular emission built in, and an extended list of IMFs, isochrones, stellar spectra, and nebular emission properties.

<strong>For more information and data access, click <a href="https://halos.as.arizona.edu/suchethacooray/dsps_ssp/">here</a>. </strong>
